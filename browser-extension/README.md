# 连接当前 Chrome

沿用你日常使用、已经登录账号的 Chrome。首次加载扩展即可，不需要为每次导入重新开窗口、重新登录。也可以继续使用藏页的独立 Chrome；那个资料目录同样会保留登录状态。

1. 在藏页「导入收藏」选择平台，点「连接当前Chrome」，下载扩展 ZIP 并解压。
2. 在常用 Chrome 打开 `chrome://extensions`，开启开发者模式，点「加载已解压的扩展程序」，选择解压后的 `cangye-login` 文件夹。
3. 在藏页复制连接码，打开 Chrome 工具栏中的藏页扩展，选择相同平台，粘贴连接码，点「连接」。首次连接时授权所选平台和本机服务。
4. 扩展显示成功后回藏页导入收藏。B 站先读取收藏夹，勾选要导入的范围。

连接码十分钟内有效且只能使用一次。扩展只在你点击时读取所选平台的 Cookie，直接发送到连接码对应的 `127.0.0.1` 本机服务；不生成含 Cookie 的 JSON 文件、不上传外部服务、不读取密码，也没有后台采集或内容脚本。安装时不授予网站访问权限；连接时才请求所选平台权限。保存的登录状态在 Windows 使用当前用户 DPAPI 加密。

这是登录状态快照，不是持续共享 Chrome。账号退出、凭据过期或切换账号后重新连接；平台要求验证时需要本人完成，再连接或保存状态，不自动绕过。非 Windows 暂不支持保存网页登录态。
