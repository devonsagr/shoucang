# 可选的 Chrome 登录快照

工具自己的 Chrome 登录窗口会复用同一个平台资料目录，保存后无需每次登录。此扩展仅用于希望沿用常用 Chrome 登录的用户，不是采集的必装组件。

1. 下载本目录或从藏页「导入收藏」下载扩展 ZIP，解压到你选择的本机目录。
2. 在常用 Chrome 打开 `chrome://extensions`，开启开发者模式，点击「加载已解压的扩展程序」，选择本目录。
3. 在当前 Chrome 正常登录所需平台，打开扩展，选择平台，点击「导出登录快照」，仅授权所选平台。
4. 在藏页「导入收藏」选中同一平台，使用「导入 Chrome 登录快照」选择生成的 JSON 文件。
5. 导入后删除该 JSON 文件。快照含登录凭据，不应上传 GitHub、发给 AI、同步到知识库或发送给别人。

扩展没有内容脚本、后台任务、外部网络请求或自动采集；只在点击时读取所选平台 Cookie 并保存本机文件。不会导出其他网站 Cookie，也不读取浏览器密码。跨浏览器不会实时同步登录，过期时重新导入一次即可。

Windows 中藏页保存的登录态使用当前系统用户的 DPAPI 加密。非 Windows 当前不能保存网页登录态，其他系统的凭据保护尚未实现。此入口不绕过验证码、登录验证或平台权限，也不能保证网页采集不触发限制。
