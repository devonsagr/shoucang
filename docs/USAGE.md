# 使用与设置

## 收藏和链接

「导入收藏」先选择平台。优先用「连接当前Chrome」沿用常用浏览器里已经登录的账号：首次加载本地扩展，复制网站连接码，在扩展选择同一平台并确认连接。以后只需在登录过期或切换账号时再连接，不为每次导入重新登录。详细步骤见 [扩展说明](../browser-extension/README.md)。

「单独登录 · 备用」也会复用本工具自己的 Chrome 资料目录。账号仍需本人登录或完成平台验证；保存登录状态不能冒充已验证收藏权限。

B 站点「选择B站收藏夹」读取当前账号的自建收藏夹，显示名称和条数；可以全选或只勾选几个，再导入。首次直接点导入也只先加载选择项，确认范围后再点一次才开始。没有勾选或收藏夹不可访问会明确报错，不擅自换成所有收藏。一个视频出现在多个夹时只保存一条，来源记录和 Markdown 保留所有实际观察到的夹名。暂不读取订阅的他人收藏夹。

新一次导入从最新收藏核对清单，新增来源进入采集队列；回收站和已永久删除来源不会自动恢复。上次中断选「续读」；十几天后增加新收藏应选最新核对，以免只接旧断点。旧正文不会全部重采，只有完整清单正文可以直接比较变化；需要核对旧文章时主动刷新该条。

小黑盒先从收藏接口分页登记稳定ID和准确标题，再处理新增材料正文。这个适配器适用于后续收藏，不是为某几条帖子硬写规则。列表优先、正文后置；接口未识别、分页有断点或验证失败会保留未完成状态。当前账号出现过安全验证时，请本人先完成验证再使用，不能靠循环重试解决。

要补齐之前缺正文的材料，勾选「同时补齐未完成」再从最新收藏核对。它只补采本次收藏清单实际返回的未完成条目，完整材料和删除记录会跳过；无需逐条点重试。续读沿用上次选项。小黑盒续读会重新经过网页原生分页，已登记ID跳过，正文不重复采集；平台拒绝后停止，已收到的有效页仍保留。

粘贴链接时默认标记为非收藏材料。字幕自动处理，无需先运行其他转写工具；若失败，先看原始来源、任务错误与时间轴完整性，再重试或明确补充原文/字幕。本人提供的字幕会保留声明来源，不伪称平台字幕。

旧材料缺正文或图片时，在原始列表点「多选」，勾选或「全选」，再点「重试收集」。完整内容跳过，已有任务不会重复排队；正文明确完整且只有缺图片时优先补存图片，原文和批注保留。失败项留在选择中并给出原因。需要账号验证时先在「导入收藏」复用已有Chrome窗口，本人完成验证并保存登录，再批量重试；不必每条重新登录，不自动解验证码。

小黑盒读取复用本工具的同一 Chrome 资料目录，不再只把 Cookie 克隆到新的无头窗口。遇到平台验证会保留真正报错的标签供本人处理。材料上的验证入口打开该条原文，已有同一原文页时保留当前页面；若仍有可见验证，保存登录会报告未通过。完成后回网站保存，再主动重试。连接当前 Chrome 仍是一次登录快照，不会永久共享浏览器；平台如果仍要求安全验证，需要本人处理。正文采集复用一个最小化的专用读取窗口，不每条弹新窗口；它仍是网页读取，并非完全没有浏览器进程。切换网站平台或关闭导入对话框不会取消后台队列，停止需点任务的停止按钮。

小黑盒文章插图按阅读宽度排列，长图预览可裁切；顶部图集和评论图片紧凑排列，X 照片与小红书笔记图集采用各自版式。原图完整保留，点击在当前页面看全图，可切换上一张、下一张和原尺寸。正文中穿插的图片仍留在对应段落。小黑盒懒加载图片由页面原生加载器提供地址，没有取得地址就显示未完成，不拿文章HTML代替图片。图片目前限单张8MB、单条200张、总量128MB；超过限额同样保留未保存状态。

## 批注与分层

每条批注写关注点和用途，不要求长文，也不要求先调 AI。

- 留作资料：全文本身有用，先备查，以后需要时调用。
- 以后细读：标出疑问、灵感和参考点，先保存，日后自己加工或让 AI 辅助。
- 稍后整理：当前先悬置，不需要批注，也不生成知识库文件。

两种第一层资料库与原始收藏分开。确认分流后仍在当前原始队列继续下一条；本人主动进入「第一层材料」再加工。二级默认仍是主题下的材料；若要形成高度凝练的个人观点、综合笔记或文章正文，另开明确任务，并审查新正文，不把批注或 AI 输出默认当作已理解。

## 位置与附件

设置中的材料归档支持根目录和相对阶段目录，二级常用目录一行一个。设置只影响后续预览；已有托管记录仍记住原位置。改变根目录不会自动迁移旧知识库，旧包相关操作需要原库可访问；需要换库时请明确迁移范围和备份，不靠改路径冒充迁移完成。

每条资料在自己的包内统一保存 `assets`，正文用相对图片链接。换层迁移整包，回收站保留恢复清单，永久删除只清理本条独占文件。发现人工改动、文件缺失或共享引用会停止并报告，不强行清库。非本工具管理的笔记不会自动删除。

## 模型与其他接入

速览是本机原句摘录，无需模型。需要按批注让 AI 整理时，在设置填写兼容 Chat Completions 的 API 根地址、模型 ID 和密钥；只在本人主动请求时发送选中材料与显式关联笔记。

本机 ASR 默认 faster-whisper `turbo`，可选 tiny/base/small/medium/large-v3；设备和模型会影响速度与准确率，没有自动获得“人工字幕准确率”的保证。缺少可用平台字幕才尝试临时音频，转写后删除临时媒体；保留原始字幕文件、完整逐段时间轴和转写来源。显卡依赖是可选，`安装转写.ps1` 和 `requirements-gpu.txt` 仅在需要时使用。

中英双语在阅读页可开关。字幕先取平台第二轨，不足时使用本机机器翻译；正文和已存档回复也可翻译。仅对实际支持语言处理，名称、链接和纯表情不编造译文。模型首次联网下载，运行文件不进 Git。

Firecrawl 和 X 官方 OAuth 是可选入口；默认 X 会话读取不要求开发者账号，仍受平台限制。后续任务或知识工具通过 REST API 或已确认 outbox 接入，不默认锁定某个 AI 客户端。
