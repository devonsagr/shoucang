# 平台与已知限制

下面描述的是实现范围，不能替代某个账号的现场核验。不要用夹具测试证明私人收藏已读完，也不要把平台末尾、正文和附件状态合并为一个“全部成功”。

| 平台 | 收藏入口 | 材料处理 | 主要边界 |
| --- | --- | --- | --- |
| B站 | 当前账号自建收藏夹先选择，再按夹和页读取；暂不含订阅他人夹 | 平台字幕优先；无字幕时尝试音频转写 | 失效内容、登录、分P、音频权限与平台响应会影响结果 |
| YouTube | 可访问播放列表；可指定稍后观看等列表 | 提取器字幕优先；否则尝试转写；原站播放器 | 私有列表、地区/年龄/账号限制及平台风控；单批列表限制需按错误提示处理 |
| 抖音 | 本人收藏页，需要实际选中收藏标签 | 字幕/临时音频尝试，本机 ASR；有可用在线地址时页内播放定位 | 签名地址可能过期；iframe 回退不能承诺逐句定位；登录、图文帖与平台限制分别报告 |
| X | 默认本人会话低速读取书签；可选官方 OAuth | 正文、图片及实际可读部分回复；视频只留原帖链接 | 非官方方式可能受条款、验证码、限流和账号限制；每次主动导入，不默认定时后台同步 |
| 小黑盒 | 本人收藏页的 `/bbs/web/profile/favours` 接口响应优先，offset分页 | 新版文章和顶部图集；已加载评论与回复；仅视频保留原链接 | 复用正常网页请求的会话和签名，不破解验证。新接口流程仍需当前账号现场验证；未知结构、分页断点、限流停止，不承诺全量评论或视频字幕 |
| 小红书 | 本人主页实际收藏标签 | 可取得正文、图集与部分评论；视频留原链接 | 账号页结构和权限差异较大，需要实机验证；无法确认标签时不把发布内容或推荐流当成收藏 |

Chrome 连接是本人授权的单平台快照，不会一直监听常用浏览器。小黑盒读取复用最小化专用窗口，平台验证时保留失败页，需要本人处理后主动重试。快照可复用登录，但不能保证任意平台网页永不要求验证。

## 同步边界

稳定来源去重，不按标题猜重复；链接别名规范到同一身份。平台收藏移除不删除本地记录。永久删除后留下来源指纹，可在同步时跳过，只有明确选择才重新收集；旧版本缺失删除事件或备份时不能凭空补齐历史。

每次新导入逐页核对清单，正文仅给新增来源采集，因此并非“完全不读旧列表”。清单有完整原文时比较同一帖变化；只有链接时，不重采就无法知道正文被修改，需主动刷新。远端若返回错误或不完整列表，工具只报告本次实际读到的范围，不保证漏项永远不存在。断点续读不能代替新一次最新核对。

勾选「同时补齐未完成」会另给清单中实际返回的旧失败、部分完成、暂停材料排队，仍跳过完整材料、删除记录和仅视频引用；排队数不表示已经成功。小黑盒在网页原生分页中重新核对已登记ID，续读仍可能读取前面的清单页；不会把临时签名持久化为可直接跳页的保证。

## 字幕、摘要与翻译

转写可以受噪声、方言、音乐、重叠说话和设备影响。稀疏片段或时间轴不匹配会显示需要核查；这是检测提示，不等于已证明全文准确。没有取得音频、平台限制下载或模型失败时必须显示未完整，不能用标题或简介替代字幕。

原文导读仅保留原文或字幕开头的相邻上下文，可能遗漏重点，不是总结。可选概要需要已经配置的模型服务，只在点击后调用；没有模型时不会用摘句冒充整体概括。模型概要可能错误，未读取图片与评论，只概括实际取得的文字；导读和概要均不进入后续整理或知识输出。主题划分是本机词语规则，允许人工改类，不读取图片文字；人工选择不会被刷新覆盖。机器翻译只支持现行语言/模型范围，不能假称平台原生双语或人工校对。

## 部署与数据

主要实机验证环境是 Windows + Chrome。Linux/macOS 的登录、GPU、播放器和文件操作需要贡献者补充验证；非 Windows 当前拒绝保存网页登录态，尚未实现其他系统的凭据保护。默认服务没有远程多用户鉴权，不应直接暴露公网。

路径配置是未来写入目的地，不是换盘搬库向导。已确认包保留原库和文件清单；云盘未挂载、旧根不可访问或文件被人工修改会停止相关文件操作，不猜测成功。不会后台扫描整库、自动合并成熟观点、自动创建外部待办或跨工具发消息。

低频网页读取仍可能触发平台限制。遇到可见验证、权限拒绝或限流请由本人处理，工具不自动破解验证或绕过登录边界。
