# 藏页 Cangye

把跨平台收藏变成可阅读、可批注、可追溯的 Markdown 材料。

藏页是一款运行在本机的收藏处理工具。先保留原文、来源、链接、图片与字幕，再由你写批注：**留作资料**，以后需要时调用；或**以后细读**，保留问题与灵感，留待消化。暂时不处理的材料可以选择**稍后整理**。它不把收藏、AI 摘要或归档动作当成你已经理解的知识。

这是早期版本，以 Windows 本机使用为主要验证环境。各平台的网页、账号权限和风控不同，有适配器并不意味着每个账号或每条材料都能采集成功。具体边界见 [平台与已知限制](docs/LIMITATIONS.md)。

## 能做什么

- 两种收集入口：登录自己的收藏页，或主动粘贴非收藏链接；两种来源分别标记。也可导入 TXT/JSON 收藏清单。
- B站、YouTube、抖音：先取平台字幕，缺少字幕时尝试临时音频和本机 faster-whisper 转写。逐句时间轴、来源、机器转写和完整性状态分别保留。视频在线播放，不保存播放副本；平台允许定位时可点字幕跳转。
- X、小黑盒、小红书：保存可取得的正文和图片，图片按原文顺序出现；评论只保存本次实际取得的部分。仅视频帖子保留原视频链接，不冒充已取得视频内容。
- 连续字幕阅读、全文搜索、可开关的中英双语阅读，已存档回复也可翻译；翻译与原文分开，机器翻译可能有误。
- 按平台、内容主题、收集状态、处理状态检索；多选和全选覆盖当前筛选的完整结果，支持批量回收、恢复与确认后永久删除。处理后继续当前列表下一条。
- **速览**从原文或字幕选出少量原句，不调用云端模型，不是 AI 总结。它只供本人筛选，不写入批注、知识库导出或后续 AI 输入。
- 增量身份去重：已有来源保持原文、批注和历史；远端取消收藏不删除本地。永久删除后留下不含原文与链接的来源指纹，后续同步跳过；本人明确选择才可重新收集。
- 独立第一层材料库，后续审查再按主题归位。Markdown 知识库根目录和各阶段目录均有设置入口，适用于 Obsidian 或普通 Markdown 文件夹。
- REST API、不可变推送预览、显式确认、附件归属与哈希检查、文件操作恢复日志，方便后续工具接入，不依赖某个 AI 客户端或任务应用。

## 快速开始

需要 Python 3.11、Chrome，以及首次安装依赖时的网络连接。建议使用独立目录。

```powershell
git clone https://github.com/devonsagr/shoucang.git
cd shoucang
.\启动.cmd
```

启动脚本首次创建项目内的虚拟环境并安装锁定依赖。随后在浏览器打开 **http://127.0.0.1:8766/**。窗口中按 Ctrl+C 停止服务。依赖安装失败会停止，不会显示虚假的启动成功。

手动安装或其他系统可按下面步骤启动；其他系统的浏览器登录和语音转写尚未完成同等实机验证：

```sh
python -m venv .venv
# 激活虚拟环境后
python -m pip install -r requirements.txt
python -m playwright install chromium
python -m uvicorn app.main:app --host 127.0.0.1 --port 8766
```

本机转写首次使用某个模型时会下载模型。默认 `turbo`，可在设置中选择其他模型；速度取决于设备。显卡加速是可选配置，参见 [使用与设置](docs/USAGE.md)。没有语音、平台拒绝音频或识别结果不完整时，工具会保留失败或需核查状态。

## 第一次使用

1. 粘贴一条链接，或在「导入收藏」选择平台，完成自己的平台登录并保存状态。
2. 浏览原文与采集状态。正文、图集、字幕、回复有各自实际取得的范围；失败可以重试。
3. 写下为什么收藏、以后如何用或想进一步想清楚什么，再选择「留作资料」或「以后细读」。先显示具体路径，原按钮变成确认保存；确认后才写文件。
4. 在「第一层材料」查看已批注的资料。以后选择自己加工，或主动调用配置的 AI；根据本人的批注和原文继续整理。需要分散到知识库主题材料区时，使用「整理提示词」作为交接背景，先审查再确认归位。

已有登录态会复用同一平台资料目录，无需每次新建登录。希望沿用常用 Chrome 账号时，可选择 [登录快照扩展](browser-extension/README.md)；它仅在点击后导出所选平台 Cookie，不是采集的必装组件。

## 知识库放在哪里

「设置 → 材料归档」可以自由填写根目录和阶段目录。留空根目录时默认使用项目内的 `data/knowledge-base`；它是个人运行数据，不在仓库中。

默认结构为：

```text
<知识库根>/
├── 收藏材料库/
│   ├── 01_调用资料/<标题--导出ID>/index.md
│   ├── 02_消化暂存/<标题--导出ID>/index.md
│   └── _回收站/
├── <本人选定的主题>/材料/
│   ├── 可调用资料/<标题--导出ID>/index.md
│   └── 待消化/<标题--导出ID>/index.md
└── 收藏处理器/<平台>/<状态>/<标题--导出ID>/index.md
```

前两项是独立第一层资料库；主题下的是第二层材料专区；最后一项仅用于本人主动选择的原始材料单独存档，首次批注分流不会同时复制一份重复原文。每条材料的图片统一在该条目录的 `assets`，第二层同包保存 `来源与批注.md`。材料默认仍是材料，知识正文需要另外明确选择人工写作或综合提炼。

改设置不会自动搬动已有材料。实际换层时，系统先冻结文件清单；本人确认后迁移整包、更新相对链接、核对内容并清理原托管位置。回收、恢复和永久删除同样按归属联动；人工改动、冲突、共享附件或越界会停止操作，独立记录仍使用的原文和附件会保留。不会递归扫描整库、覆盖已有笔记或自动分类所有笔记。

## 关于同步和费用

新一次导入从最新收藏开始逐页核对清单，给新来源排队正文采集；「续读」只接上次断点。为避免漏项，它不会承诺只请求一页增量，也不会反复采集所有旧正文。清单带完整正文时能比较同一来源的内容变化并留旧版本；只有链接的平台需要手动刷新旧材料才能检查正文变化。平台未返回明确末尾时不标记全部完成。

采集不要求配置 AI。速览是本机摘录；语音转写与中英翻译在本机处理。需要 AI 按批注整理时，再设置兼容 Chat Completions 的服务、模型和密钥。只发送本人主动选择的材料与关联笔记；服务费用由提供者决定。Firecrawl、X 官方 OAuth 等接入均为可选，不是默认必需项。

## 隐私与发布

仓库只包含代码、公共文档、合成测试及界面素材。`data`、`tmp`、`config.json`、登录资料、数据库、模型、个人笔记、收藏、截图与凭据均不发布。个人部署不要把这些运行目录推送到任何公开仓库。

服务默认只监听回环地址，写请求要求同源和明确请求头，未提供远程多用户认证。Windows 登录快照使用当前用户 DPAPI；非 Windows 当前拒绝保存网页登录态，尚未实现其他系统的凭据保护。Cookie JSON 包含登录凭据，只用于本机导入，导入后删除，不发给 AI 或其他人。遇到平台验证、权限拒绝或限流会停止或暂停，不自动破解验证；低速读取仍不能保证账号零风险。
